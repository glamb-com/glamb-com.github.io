# Glamb Com — Audiology Clinic Website

A complete static, responsive demo website for an audiology and hearing-care clinic.

## Included
- Home page with strong service positioning
- Comprehensive audiology service catalog
- Hearing-aid technology page
- Hearing testing page
- Tinnitus support page
- Transparent sample pricing
- About, FAQ, contact, accessibility, privacy and terms pages
- Mobile navigation and responsive layouts
- Client-side demo appointment form (no server transmission)
- Local image assets for reliable static hosting

## Run locally
Open `index.html` directly or serve the folder with any static HTTP server.

## GitHub Pages
Upload the files to the repository root and enable GitHub Pages from the default branch.

## Important
Contact details and prices in this demo are placeholders. Replace them before production use. For a real healthcare organization, use a compliant form/workflow for any protected or sensitive health information.
